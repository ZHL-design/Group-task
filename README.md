## ✨ 功能概述（C 语言实现）

| 功能 | 使用的数据结构 | 命令 | 说明 |
| :--- | :--- | :--- | :--- |
| 加载并显示文本 | 线性表（动态数组） | 启动自动加载 | 支持 UTF-8 编码文件 |
| 删除指定行 | 线性表 + 栈（撤销） | `d <行号>` | 删除后可撤销 |
| 撤销操作 | 栈（Undo Stack） | `u` | 最近一次删除可恢复 |
| 多关键词高亮 | 链表（关键词存储） | `h` 设置 → `s` 显示 | 红色高亮显示匹配词 |
| 关键词搜索 | 串（Brute-Force） | `f <关键词>` | 显示包含关键词的所有行 |
| 统计信息 | 串 | `c` | 行数、字符数、平均行字符数 |
| 词频统计 | Trie 树 | `w` | 基于 Trie 树统计词频并排序 |
| 单词共现分析 | 图（邻接表） | `co` | 统计相邻单词共现次数 Top10 |
| 插入新行 | 线性表（动态数组） | `ins <行号> <内容>` | 在指定位置插入一行 |
| 操作日志 | 循环队列 | `log` | 查看最近 10 条操作记录 |
| 保存处理结果 | 文件 I/O | `p` | 生成 `<原文件名>_processed.txt` |

## 🔧 编译与运行

### 环境要求
- Windows 系统
- 编译器：Dev-C++ / Visual Studio / MinGW（任选其一）
- 控制台需支持 UTF-8 编码

### 编译步骤

**Dev-C++：**
1. 打开 `main.c` 或 `work.cpp`
2. 点击「编译运行」按钮（或按 `F11`）

**Visual Studio：**
1. 新建「控制台应用程序」项目
2. 将代码粘贴到 `main.c`
3. 按 `Ctrl + F5` 运行

**MinGW（命令行）：**
bash

gcc -o editor.exe main.c -lws2_32
### 运行说明
1. 启动程序后，输入要处理的 `.txt` 文件路径
2. 根据提示输入命令进行操作
3. 输入 `q` 退出程序

## 📋 命令速查表
d <行号>      - 删除指定行（例：d 3）

u              - 撤销上一次删除

s              - 显示文本（带关键词高亮）

f <关键词>     - 搜索包含关键词的行（例：f 你好）

c              - 显示统计信息

w              - 显示词频统计结果

h              - 设置高亮关键词（空格分隔多个词）

ins <行号> <内容> - 在指定行前插入内容

log            - 查看操作日志

co             - 显示单词共现图 Top10

p              - 保存处理结果到新文件

q              - 退出程序

## 🏗️ 数据结构设计
┌─────────────────────────────────────────────────┐

## 📝 注意事项

- 输入文件路径时，可以使用**绝对路径**（如 `C:\test.txt`）或**相对路径**（如 `test.txt`）
- 中英文混合文本均可正常处理
- 搜索和词频统计**不区分大小写**
- 高亮功能需要先通过 `h` 命令设置关键词，再通过 `s` 命令查看效果
