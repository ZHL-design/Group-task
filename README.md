# 文本处理工具（C语言核心）

本项目为课程作业，**核心功能全部使用 C 语言实现**。  
额外提供了一个 HTML 前端界面，仅用于展示效果，**不作为作业主体**。

---

## 项目结构

| 文件 | 说明 |
|------|------|
| `work.cpp` | **C 语言源代码**（作业主体，包含所有算法） |
| `index.html` | 额外制作的图形界面演示（非必须，仅为美观） |
| `README.md` | 本说明文件 |
| `test.txt` | 测试用文本文件 |

---

## 功能概述（C 语言实现）

- 加载并显示文本文件
- 删除指定行（支持撤销操作）
- 关键词搜索
- 统计信息（行数、字符数、平均行字符数）
- 词频统计（基于 **Trie 树**）
- 多关键词高亮显示
- 保存处理结果（生成 `_processed.txt`）
